# Still website (v4 concept)

The concept site for Still, a small wearable for vertigo and motion sickness that rests behind the ear. In development, not yet approved for sale, and not for public promotion before ARTG listing.

- `index.html` is the whole page: styles, scripts and fonts are inline, so it works offline and loads nothing from third parties.
- `media/` holds the films (H.264 MP4, with lighter versions for phones) and images (WebP).
- `netlify.toml` and `robots.txt` keep the site out of search engines and set the video headers.

To preview, open `index.html` in a browser, or drag this folder into Netlify.

Product images are concept renders and AI-generated visualisations; the people shown are not real people or users, and the app screens are an interface concept.
